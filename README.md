# Your First Code

This repository contains a single C program: `main.c`.

## What Does the Program Do?

The program prints `"Hello Holberton"` 42 times, each on its own line.

## Compile and Run

1. Compile the program using a C compiler such as `gcc`:

```sh
gcc main.c -o main
```

2. Execute the compiled program:

```sh
./main
```

Running these commands should display the greeting 42 times.
